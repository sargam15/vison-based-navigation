# Vision‑Based Navigation for Underwater ROVs

Real-time monocular visual odometry and pose estimation for underwater ROVs/AUVs using OpenCV and feature-tracking algorithms.

---

## 🚀 Features

- Real-time monocular visual odometry
- ORB/SIFT-based feature matching
- Essential matrix + pose estimation
- Visual trajectory generation

---

## 🛠️ Requirements

- Python 3.8+  
- OpenCV  
- NumPy  
- Matplotlib (optional)

pip install -r requirements.txt
